CUSTOM MAPS — OpenThandor

Put map-editor .thmap projects directly in maps/ beside thandor.exe. Open Choose game and click Custom maps beneath Campaigns. The list shows Map, Planet, Size, Players and Author. Players is the total active faction count, shown once. Select a map, press Start, choose your faction, then continue through the briefing and Begin.

No levelNN.pck installation, numbered map slot, catalog entry or stock availability-mask bit is needed. The original game PCKs are still required for shared assets. The selected project supplies its own LEV, FLD, text and embedded custom assets in memory. It does not install or overwrite stock archives. Re-enter Custom maps to rescan the directory.

In the updated editor, Players > Human player slot sets the default faction preselected for the player. All other active factions are automatically computer-controlled. The player can select another playable faction; the previous choice becomes computer-controlled. Computer mode toggles are locked for custom games. Golrathen graphics remain computer-only. The original human-prefix/slot restriction does not limit custom-map choices. Old projects without an explicit default use their old human-slot value, bounded to a playable active faction.

Set Author in the editor's Map settings, press Enter and save the .thmap. Older projects without an author display Unknown. The author and default-player setting survive project save/reopen and Undo/Redo in the updated editor. Older editor versions can read the project but may omit these new metadata keys on a later save.

This is a local single-player custom-map feature. It does not add custom-project network transfer or campaign sequencing. Validation covers fresh local launches; reopening a custom-map savegame in a new process is not certified by this update.

To edit a terrain texture outside the editor, open the .thmap as a ZIP and replace the matching textures/terrain/a.tga through z.tga entry. Use a 256x256 true-color TGA and preserve alpha on the tile edges. Leave map.ini and its terrain_crc values in place. The editor and game use an edited image as a map-local ground texture when the project loads.


Developer notes
The current project format is a standard ZIP with map.ini at its root. Legacy PCK projects with editor/project.txt (V1/V2/V3) are still supported. Keys author and default_human_faction are percent-encoded text and a 1-based decimal faction index respectively. The original runtime image is copied into the normal arena; custom assets take precedence only while their project is active. A private text alias supplies the project's title and briefing without replacing stock alias pages. Project loading validates archive sizes, entry paths, the LEV placement/path tables, FLD bounds and text resources before launch. Invalid projects remain listed with an error and Start disabled. Missing maps/ produces an empty-list explanation.
