**Thandor Patch 6 - Open Thandor @VERSION@**

Deutsch: `Thandor-Patch-6.exe` installiert Open Thandor @VERSION@ (64-Bit, Windows 10 oder neuer) als Patch in eine
vorhandene Thandor-Vollversion (der Ordner mit `DATEN.PCK`; Patch 5 wird nicht vorausgesetzt). Die bisherige `thandor.exe` wird als `thandor-1.05.exe`
gesichert; die Deinstallation stellt sie wieder her. Spielstände, `thandor.ini` und die Spieldaten bleiben unberührt.
Das Setup ist nicht signiert, SmartScreen kann deshalb warnen. Die Spieldaten sind nicht enthalten.

English: `Thandor-Patch-6.exe` installs Open Thandor @VERSION@ (64-bit, Windows 10 or newer) as a patch onto an
existing full Thandor installation (the folder with `DATEN.PCK`; patch 5 is not required). The existing `thandor.exe` is kept as `thandor-1.05.exe`;
uninstalling puts it back. Saves, `thandor.ini` and the game data are not touched. The setup is not signed, so
SmartScreen may warn. The game data is not included.
